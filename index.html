How this lab works

  • Real problems first. Each tool starts from evidence that people are stuck: forum questions, consumer reports, recent rule changes.
  • Accuracy over volume. Few tools, checked against primary sources, with the date they were last checked.
  • Private by design. Tools run in your browser. Nothing you type is sent to us.
  • Open. The code and the lab notebook are public on GitHub.
